# Math Notes

This is my personal repository for self-studying mathematics. It contains four kinds of artifacts:

- **Flashcards** — for spaced repetition in [Anki](https://apps.ankiweb.net/).
- **Self-check questions** — a set of compiled PDFs of self-check questions, one per topic.
- **Essays** — write-ups of deeper explorations of individual topics.
- **Workbooks** — ordered questions and proof tasks to work through.

## Flashcards

The `*.note` files under [flashcards/](flashcards/) are the source files of the flashcards, in a simple human-readable format.

To import these notes into Anki, install the [Notatki Anki addon](https://ankiweb.net/shared/info/541850746). Then from the `File` menu select `Import Models and Notes...` and point to the `flashcards/` directory.

We recommend the [Notatki Visual Studio Code extension](https://marketplace.visualstudio.com/items?itemName=aradzie.notatki) for editing these note files. See the [notatki](https://github.com/aradzie/notatki) repository for more details.

You can preview these notes [online](https://aradzie.github.io/math-notes/notes.html).

## Self-Check Questions

The [self-check/](self-check/) directory collects self-check questions covering various mathematical topics, meant to be worked through as active recall rather than read passively. Each topic compiles to its own standalone PDF.

## Essays

The [essays/](essays/) directory collects write-ups from conversations where I dug into a math topic in depth, kept around because rereading them later helps the ideas stick. Each essay compiles to its own standalone PDF.

## Workbooks

The [workbooks/](workbooks/) directory contains standalone PDFs of questions and proof tasks to work through.
