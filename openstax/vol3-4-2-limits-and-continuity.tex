For the following exercises, find the limit of the function.

\begin{enumerate}[start=1]
\item $\lim_{(x,y)\to(1,2)}x$
\item $\lim_{(x,y)\to(1,2)}\frac{5x^{2}y}{x^{2}+y^{2}}$
\item Show that the limit $\lim_{(x,y)\to(0,0)}\frac{5x^{2}y}{x^{2}+y^{2}}$ exists and is the same along the paths: $y\text{-axis}$ and $x\text{-axis}$, and along $y=x$.
\end{enumerate}

For the following exercises, evaluate the limits at the indicated values of $x$ and $y$. If the limit does not exist, state this and explain why the limit does not exist.

\begin{enumerate}[resume]
\item $\lim_{(x,y)\to(0,0)}\frac{4x^{2}+10y^{2}+4}{4x^{2}-10y^{2}+6}$
\item $\lim_{(x,y)\to(11,13)}\sqrt{\frac{1}{xy}}$
\item $\lim_{(x,y)\to(0,1)}\frac{y^{2}\sin x}{x}$
\item $\lim_{(x,y)\to(0,0)}\sin(\frac{x^{8}+y^{7}}{x-y+10})$
\item $\lim_{(x,y)\to(\pi/4,1)}\frac{y\tan x}{y+1}$
\item $\lim_{(x,y)\to(0,\pi/4)}\frac{\sec x+2}{3x-\tan y}$
\item $\lim_{(x,y)\to(2,5)}(\frac{1}{x}-\frac{5}{y})$
\item $\lim_{(x,y)\to(4,4)}x\ln y$
\item $\lim_{(x,y)\to(4,4)}e^{-x^{2}-y^{2}}$
\item $\lim_{(x,y)\to(0,0)}\sqrt{9-x^{2}-y^{2}}$
\item $\lim_{(x,y)\to(1,2)}(x^{2}y^{3}-x^{3}y^{2}+3x+2y)$
\item $\lim_{(x,y)\to(\pi,\pi)}x\sin(\frac{x+y}{4})$
\item $\lim_{(x,y)\to(0,0)}\frac{xy+1}{x^{2}+y^{2}+1}$
\item $\lim_{(x,y)\to(0,0)}\frac{x^{2}+y^{2}}{\sqrt{x^{2}+y^{2}+1}-1}$
\item $\lim_{(x,y)\to(0,0)}\ln(x^{2}+y^{2})$
\end{enumerate}

For the following exercises, evaluate the limit of the function by determining the value the function approaches along the indicated paths. If the limit does not exist, explain why not.

\begin{enumerate}[resume]
\item $\lim_{(x,y)\to(0,0)}\frac{xy+y^{3}}{x^{2}+y^{2}}$
\begin{enumerate}[label=(\alph*)]

  \item Along the $y\text{-axis}$ $(x=0)$
  \item Along the path $y=2x$
\end{enumerate}
\item Evaluate $\lim_{(x,y)\to(0,0)}\frac{xy+y^{3}}{x^{2}+y^{2}}$ using the results of previous problem.
\item $\lim_{(x,y)\to(0,0)}\frac{x^{2}y}{x^{4}+y^{2}}$
\begin{enumerate}[label=(\alph*)]

  \item Along the $y\text{-axis}$ $(x=0)$
  \item Along the path $y=x^{2}$

\item Evaluate $\lim_{(x,y)\to(0,0)}\frac{x^{2}y}{x^{4}+y^{2}}$ using the results of previous problem.

Discuss the continuity of the following functions. Find the largest region in the $xy\text{-plane}$ in which the following functions are continuous.

\begin{enumerate}[resume]
\item $f(x,y)=\sin(xy)$
\item $f(x,y)=\ln(x+y)$
\item $f(x,y)=e^{3xy}$
\item $f(x,y)=\frac{1}{xy}$
\end{enumerate}

For the following two exercises, determine the region in which the function is continuous. Explain your answer.

\begin{enumerate}[resume]
\item $f(x,y)=\frac{x^{2}y}{x^{2}+y^{2}}$
\item $f(x,y)=\frac{\sin(x^{2}+y^{2})}{x^{2}+y^{2}}$
\item Determine whether $f\left( x,y \right)$ is continuous at $\left( 0,0 \right)$. $f(x,y)=\begin{cases}\dfrac{x^{2}y}{x^{2}+y^{2}} & \text{if }(x,y)\ne(0,0) \\ 0 & \text{if }(x,y)=(0,0)\end{cases}$
\item Determine whether $g(x,y)=\frac{x^{2}-y^{2}}{x^{2}+y^{2}}$ is continuous at $(0,0)$.
\item Create a plot using graphing software to determine where the limit does not exist. Find where in the coordinate plane $f(x,y)=\frac{1}{x^{2}-y}$ is continuous.
\item Determine the region of the $xy\text{-plane}$ in which the function $g(x,y)=\arctan(\frac{xy^{2}}{x+y})$ is continuous. Use technology to support your conclusion.
\item Determine the region of the $xy\text{-plane}$ in which $f(x,y)=\ln(x^{2}+y^{2}-1)$ is continuous. Use technology to support your conclusion. (Hint: Choose the range of values for $x$ and $y$ carefully!)
\item At what points in space is $g(x,y,z)=x^{2}+y^{2}-2z^{2}$ continuous?
\item At what points in space is $g(x,y,z)=\frac{1}{x^{2}+z^{2}-1}$ continuous?
\item Show that $\lim_{(x,y)\to(0,0)}\frac{1}{x^{2}+y^{2}}$ does not exist at $(0,0)$ by plotting the graph of the function.
\item \techrequired Evaluate $\lim_{(x,y)\to(0,0)}\frac{-xy^{2}}{x^{2}+y^{4}}$ by plotting the function using a CAS. Determine analytically the limit along the path $x=y^{2}$.
\item \techrequired
\begin{enumerate}[label=(\alph*)]
  \item Use a CAS to draw a contour map of $z=\sqrt{9-x^{2}-y^{2}}$.
  \item What is the name of the geometric shape of the level curves?
  \item Give the general equation of the level curves.
  \item What is the maximum value of $z$?
  \item What is the domain of the function?
  \item What is the range of the function?
\end{enumerate}
\item True or False: If we evaluate $\lim_{(x,y)\to(0,0)}f(x)$ along several paths and each time the limit is $1$, we can conclude that $\lim_{(x,y)\to(0,0)}f(x)=1$.
\item Use polar coordinates to find $\lim_{(x,y)\to(0,0)}\frac{\sin \sqrt{x^{2}+y^{2}}}{\sqrt{x^{2}+y^{2}}}$. You can also find the limit using L'Hôpital's rule.
\item Use polar coordinates to find $\lim_{(x,y)\to(0,0)}\cos(x^{2}+y^{2})$.
\item Discuss the continuity of $f(g(x,y))$ where $f(t)=1/t$ and $g(x,y)=2x-5y$.
\item Given $f(x,y)=x^{2}-4y$, find $\lim_{h\to0}\frac{f(x+h,y)-f(x,y)}{h}$.
\item Given $f(x,y)=x^{2}-4y$, find $\lim_{h\to0}\frac{f(1+h,y)-f(1,y)}{h}$.
\end{enumerate}
