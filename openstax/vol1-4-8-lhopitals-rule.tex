For the following exercises, evaluate the limit.

\begin{enumerate}[start=1]
\item Evaluate the limit $\lim_{x\to \infty}\frac{e^{x}}{x}$.
\item Evaluate the limit $\lim_{x\to \infty}\frac{e^{x}}{x^{k}}$.
\item Evaluate the limit $\lim_{x\to \infty}\frac{\ln x}{x^{k}}$.
\item Evaluate the limit $\lim_{x\to a}\frac{x-a}{x^{2}-a^{2}},\,a\ne0$.
\item Evaluate the limit $\lim_{x\to a}\frac{x-a}{x^{3}-a^{3}},\,a\ne0$.
\item Evaluate the limit $\lim_{x\to a}\frac{x-a}{x^{n}-a^{n}},\,a\ne0$.
\end{enumerate}

For the following exercises, determine whether you can apply L'Hôpital's rule directly. Explain why or why not. Then, indicate if there is some way you can alter the limit so you can apply L'Hôpital's rule.

\begin{enumerate}[resume]
\item $\lim_{x\to0^{+}}x^{2}\ln x$
\item $\lim_{x\to \infty}x^{1/x}$
\item $\lim_{x\to0}x^{2/x}$
\item $\lim_{x\to0}\frac{x^{2}}{1/x}$
\item $\lim_{x\to \infty}\frac{e^{x}}{x}$
\end{enumerate}
